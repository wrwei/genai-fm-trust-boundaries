# AMR v2 实验结果：从局部检查到运行时保障

2026-09-21。本轮按照[已批准设计](research_amr_case_redesign_2026-09-21.md)与[执行计划](research_amr_v2_execution_2026-09-21.md)完成有限实验。实现、原始记录、证明及独立复核集中于 [amr-advisory-v2](../../../formal-artefacts/amr-advisory-v2/README.md)。历史生成与复现实验保持原样。

**本轮的主要结果是建立了与正文对应的可检验区分：源码—模型、物理谓词、当前执行许可、条件进展分别需要证据。** 案例由原先的受限生成可行性示例，推进为包含四类失效对照、离散组合证明和真实建议接入的工业仿真案例。它仍是一个两车、固定任务、确定性参考环境的机制研究，不能据此验证整篇综述的普遍结论。

## 1. 场景与冻结范围

两台 AMR 各运输一次，从狭窄共享通道两端请求通行，途中有行人横穿区域。设计时生成的受限控制器给出最终 SelectA/SelectB/Defer 及运动策略输出；运行时模型只返回建议 A/B。可信接口管理建议邮箱、预约与动作施加，独立几何检查实际轮廓、占用和完成。

v2 要求：合法且无歧义的建议应影响选择；缺失或冲突时按登记顺序回退。旧五布尔量接口不能表达任意到达次序，因此显式冻结为 A rank 0、B rank 1，各登记一次，实验标识为 `amr-advisory-contract/v2/fixed-registration-A-before-B`。这不是一般动态 FIFO。

六份历史初始回复共五个不同源码身份，全部重新检查 32 个选择输入与 1,792 个动作输入。旧契约仍为 6/6 通过；更强的 v2 为 **1/6 通过**，按冻结顺序选择 P3-R1。该变化说明旧可选建议策略与新功能义务不同，不能回写成历史结果错误或新任务生成成功率。实际部署原始源码 SHA-256 为 `9eaa530b58253c1a07c6369882ed59eacb4cfac7dc40850e4100d31f387a47cd`。

E1–E4 的故障版本全部明确构造；不计入自然模型错误率，也不用于“CKA 比其他方法更强”的比较。

E1 的最小输入是 OwnerFree、RequestA、RequestB 为真，PreferA 为假、PreferB 为真。同一 P1-R1 原始源码实际返回 A；故障提取只把目标模型这一分支变为 B。旧安全约束对两者都通过，故障模型对新功能要求也全部通过，但源码新功能和源码—模型对应均失败。完整 v2 接受流程正确拒绝该候选。

## 3. CKA 在本案中的实际作用

[AMR_Protocol.thy](../../../formal-artefacts/amr-advisory-v2/hol/AMR_Protocol.thy) 已在 Isabelle2025-2 成功构建；最终日志为 2026-09-21 22:51:34 完成。关键结果的内核依赖检查未发现跳过证明或 oracle。复用的是已有 `Bridge_Trace_Repair` 的有限交错迹语义，不宣称已经建立整个 CKA 代数实例。

这里先定义可执行操作关系，再分别定义可信开放协议 P_open、只提供建议事件的 D、由请求/首个回复/持久读取状态定义的因果接口 K_T。`operational_embedding` 证明实际离散系统运行能够分解到这些组件；`component_authority` 复用 `authority_boundary_traces`；独立参考协议模拟给出 `open_authority`，最终合成 `system_authority`。K_T 没有用“所有安全迹”作定义，环境许可更新也保留在可见投影中。

因此，本案的 CKA 角色是：**在可信协议和接口不变时，为替换满足输入约束且不直接产生控制事件的建议提供者，给出有条件的权限包含结论。** 建议可以影响选择；它不能自行扩张受控事件权限。这没有免除可信协议模拟证明，也没有证明这种组织方式更短、更易维护或优于直接状态机方法。

设计 §6.3 的“撤除建议静默前提”见证明确复用已经检查并由 AMR 理论导入的 [`controlled_advice_counterexample`](../../../formal-artefacts/cka-repair/Bridge_Trace_Repair.thy)：可信语言只有空迹，建议方却可发出一个受控事件 `[True]`，交错后的可见投影因而不再包含于可信语言。这里将 True 解释为一个控制事件标记；它是一般有限语言的前提反例，不冒充本轮新 AMR 绕过执行器的物理运行。E4 则提供另一个独立见证：保留安全包含仍可能没有进展。

| 义务 | 本轮完成状态 |
|---|---|
| O1 原始候选对应 | 每个历史源码在完整 1,824 输入域重验，保留精确字节、失败输入与提取故障对照；有限 translation validation |
| O2 单步操作模拟 | `initial_simulation`、`step_simulation`、`finite_word_simulation` 对独立参考协议证明；Clear 几何作为外部事实 |
| O3 组合解释 | 真实操作组件分解、建议静默、因果接口与权限包含在 AMR 模型中完成；不是仅将整体安全迹改名为组件 |
| O4 条件授权进展 | `source_next` 将原子 Service/Validate 锁存绑定到持久邮箱与 F；`authorization_from_any_pending` 在任意 pending 下、最多三个提供的 Service 机会内产生 Grant，允许任意有限良性间隔及任意建议（含一直没有建议） |
| O5 实现与物理联系 | 432 状态 × 27 输入 = 11,664 个 Python/HOL 核心转移相同；432 状态 × 3 建议 = 1,296 个原始源码/HOL 选择相同；另有独立物理重放。尚无完整 Python 或连续物理精化证明 |

O4 要求 Grant 前存在有效请求、owner 空闲且动作许可保持可用，并明确供给 Service；良性间隔包括建议事件、读取和相同有效许可的观测。该定理没有覆盖任意其他事件交错或无限公平调度，更没有证明整段运输完成。完整运输完成在当前任务中按设计作为仿真结果交付。

正式复核曾发现持久邮箱被错误抽象为读取后清空、来源选择与进展未充分连接的问题；最终模型已修正，并重新构建、导出、核对。最新结果使用 [conformance-final.json](../../../formal-artefacts/amr-advisory-v2/evidence/conformance-final.json)，较早对应记录作为历史保留，不与最新理论哈希混用。

## 4. 物理实验与独立检查

[物理批次](../../../formal-artefacts/amr-advisory-v2/evidence/physical/20260921T144921Z/summary.json) 保留全部 15 次运行。**15/15 指预期现象均被观察到，其中包括故意保留的错误；不能写成 15 次全部安全。**

| 组别 | 结果 |
|---|---|
| P-A / P-B / P-none | 首次获准分别 A / B / A；均在 58.9 s 完成两个任务，未发现占用或权限违例 |
| E2-center / E2-whole | 57.3 / 58.9 s 完成；提前释放 2 / 0 次；前 6,223 条记录相同，25.85 s 首次分歧 |
| E3a-bad / E3a-good | 非法 Grant 1 / 0 次；运动模型均保持停止 |
| E3b-bad / E3b-good | 非法 Proceed 1 / 0 次；坏版本实际移动 0.0025 m、达到 0.05 m/s，好版本保持停止 |
| E4-wait / E4-fifo | 无建议等待至 120 s 无授权 / 不等待建议并在 58.9 s 完成 |
| B2-temporary / B2-permanent | 66.1 s 完成 / 120 s 内没有完成；正确区分暂时和持续物理阻挡 |
| Brake-inside / Brake-outside | 1 m/s、固定危险边界；充分条件成立 / 不成立；停车余量 0.5691 / 0.5491 m，两者均停稳 |

原始连续几何检查在非专用制动校准中检查 618,436 个成对区间，碰撞和未决列表均为空。独立审计重新执行 23,557 次原始源码输出检查、132,020 个机器人运动区间、616,374 个连续矩形分离证书，以及全部 14 次释放和 14 次完成的实际状态。独立几何实现不调用被测 Clear 或历史碰撞 oracle；它仍共享参考 plant 与原始语言解释器。两套区间计数不同来自划分粒度，不能视作样本数翻倍。

预检发现旧制动计算把施加延迟写为 0.08 s，而实际队列为 0.10 s。本轮单独的有效参数副本将它改为 0.10 s、总反应上界 0.27 s；历史文件不改写。制动校准实际观测龄为 0.05 s，计算充分界 1.3341 m，两例分别取其上下 0.01 m。充分条件外仍未碰撞，只表明这一运行未出事，不能扩大保证域。B2 在 t=10.68 s、约 0.000786 m/s 触发，不能替代这组独立 1 m/s 校准。

物理批次的预运行清单绑定了 physical/plant/oracle/controller/simulation、参数和源码，但遗漏部分间接代码。最终清单补齐**当前快照**；独立重放检验已记录后果；二者都不能追溯证明当时遗漏的代码版本。此缺口及继承但未执行的旧 stress 标签已在[独立物理复核](../../../formal-artefacts/amr-advisory-v2/physical-review.md)明确记录。

## 5. 六次真实运行时建议

使用已授权的 DeepSeek `deepseek-flash`：三种相同任务事实的表述各两次，最多 128 输出 token，关闭 thinking，严格单字段 JSON，逐请求最多一次 POST、无重试。A 截止时间 30 分钟、B 为 10 分钟，排序规则是优先较早期限。此处评价的是建议进入接口并产生影响，不是让简单排序题承担模型规划能力评测。

调用前冻结区外接近等待位的参考运动和 **3.63 s** 窗口。网络调用与按真实时钟推进的确定性接近记录并行，窗口没有为 API 等待而延长。六次回复均为 `{"prefer":"B"}`，在 0.969–1.297 s 到达，均在截止前被严格邮箱接受；原始源码均返回 SelectB 并获准 B。对应无建议控制先选 A，说明建议在此受限接口中确实有影响。

实际决策记录位于 3.734–3.750 s：截止后源码复核、选择和决策记录合计花费 0.104–0.120 s，最大推进滞后 0.015 s。车辆在等待位停止；这不是完整实时机器人控制实验，也未验证物理监控器的 20 ms 计算界或真实建议下的全程运输。所有内容、HTTP 原始记录、调用标记、时间与 token 用量均保留，并由[离线审计](../../../formal-artefacts/amr-advisory-v2/advice-review.md)复核；没有额外调用。


## 6. 对正文的用法与完成边界

本轮真实建议使用 644 输入、42 输出 token；含此前 36 次调用，累计记录 42 次调用。用量是实验复现信息。

正文可以用 B1/E1 解释规格与源码对应，用 E2 解释物理解释义务，用 E3/E4 解释建议权限、当前执行状态与进展分离。组合定理给出其中离散协议一段的保证，有限实现检查与物理轨迹明确连接的强度。该证据结构支持正文关于“局部验证需要额外联系才成为系统保障证据”的具体论点；不把一个案例升级为综述所有结论的普遍实证验证。

唯一成稿入口仍为 [review_integration_2026-09-15.md](review_integration_2026-09-15.md)，本轮新增 I28 作为 AMR 案例替换块。活跃 TeX、主书目、Overleaf 分支及 9 月 15 日旧预览均未更新。研究成果留在 main；成稿同步沿用用户指定流程。

本轮完成的是：冻结的 E1–E4/B1/B2 证据覆盖、最低离散形式目标、有限源码/协议对应、15 次物理对照、6 次真实建议及其复核。仍开放的研究问题是完整 Python/物理精化、动态任务公平性、真实硬件与更广环境、时限与性能优化，以及 CKA 相对其他组织方法的维护收益。它们不作为本轮已完成实验的结论。

最终统一测试运行 30 项，61.113 s，全部通过；离线真实建议审计重执行结果逐项相同。证明源、最终对应输入、15 份物理原始轨迹身份再次核对。[独立收尾复核](../../../formal-artefacts/amr-advisory-v2/closure-review.md)未发现关键或重要问题；一般非静默建议反例的说明缺口已补齐。[最终检查记录](../../../formal-artefacts/amr-advisory-v2/evidence/final-verification.json)与[当前证据清单](../../../formal-artefacts/amr-advisory-v2/evidence-manifest.json)给出验收入口，后者是事后快照，不替代预运行清单。
