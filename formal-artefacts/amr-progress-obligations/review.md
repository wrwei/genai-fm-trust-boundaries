1. **Original progress premise needed explicit attribution.** The original scenario already requires that the reservation holder can exit and that there is no permanent hardware fault. A permanently stationary plant is a valid countermodel to the numeric speed/forward-acceleration envelope alone, but does not satisfy that complete qualitative progress premise. The new design, README and Chinese results now explicitly say the mutation removes this premise. The contribution is quantitative progress obligations and evidence about their necessity; it is not a newly discovered defect in the unchanged nominal implementation or a refutation of the original conditional scenario claim.
2. **The first timing audit silently accepted a missing observation delivery.** Removing A's `observation_received` record at 1.0 s from a retained trace still passed: the audit checked latency only for packets that appeared. The corrected audit requires every sampled packet due before the trace ends to be delivered, and rejects duplicate delivery. Focused missing/duplicate delivery tests now pass. Independent inspection also confirmed that each of the four real retained traces contains 2,356 due samples and exactly 2,356 distinct deliveries, so the finding did not change their measured results.

The delayed-command negative test reaches the command-delivery assertion; a preliminary concern that it only tested chronology was disproved by executing the mutation and was withdrawn. The final test additionally sorts the changed trace and expects the specific delivery diagnostic.

No remaining substantive correctness finding was identified within this scope.

## Exact limits of the result

The reference routes take about **29.7818542495 s** under uninterrupted Proceed and the exact reference profile. The **70.2 s** two-task value is a conservative accounting result conditional on the local grant/start/travel/finish inequalities. Four traces satisfy those inequalities and complete their last task at **58.9 s**; this does not discharge the inequalities for every schedule or environment.

The stationary mutation starts at rest, so zero speed and zero forward acceleration satisfy the numeric upper bounds; no moving braking episode is needed, and its Brake implementation is inherited. It intentionally lacks the physical exit capability and differs from the exact reference plant. The 120-second execution is a bounded witness. The separate HOL constant-function model expresses non-completion at every mathematical time; it does not prove an infinite Python execution or full plant/controller refinement.

There is still no mechanized bridge from the source/driver scheduling and floating-point plant implementation to the profile and timestamp theorems, no arbitrary-interruption or hardware progress guarantee, and no formal proof of the numerical geometry implementation. One constructed mutation and finite comparisons do not estimate a natural model failure rate. These remaining obligations are clearly stated rather than represented as completed work.
