# English claim guide for a curated artefact deposit

This guide identifies the retained evidence underlying the active manuscript. It is an index of bounded claims, not a declaration that the entire repository or every old theory is verified. Each package README gives its own assumptions, commands and evidence manifests. A deposit should preserve the selected source bytes, raw advisory replies, manifests, logs and the versions used to produce the paper's results.

The historical files `isabelle/Bridge_CKA.thy`, `isabelle/Bridge_Progress.thy` and `lean/Bridge.lean` contain admitted, axiomatized or unfinished claims. Keep them segregated as historical material or exclude them from the submission deposit. The active manuscript does not rely on their open statements as proved results. `paper/figures/bridge_model.py` retains historical output keys such as `fairness` and `cka_holds`; [`PROVENANCE.md`](PROVENANCE.md) maps those keys to the paper's bounded predicates. Do not relabel their scope by renaming keys alone.
