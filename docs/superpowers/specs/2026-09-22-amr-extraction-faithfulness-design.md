## 冻结范围

新增 formal-artefacts/amr-extraction-faithfulness/，仅导入 Isabelle Main。表达式含布尔常量、命名事实、not、变元数 and/or；源规则按顺序取首个成立条件。目标为 PUSH/LOAD/NOT/AND n/OR n 栈指令，目标关系保留全部启用规则。严格表达式纯且输入为总布尔赋值，因此 source 短路与 target 全求值没有可见副作用差异；算术、异常、共享可变状态和传感器语义不在此元定理中。

目标提取与现有 model.py 相同：递归后缀编译；not 对尾随 NOT 做消去；每一规则条件与所有更早原条件的否定合取，不改变 action/next_mode。没有匹配规则时，Python 抛出特定 no-matching ValueError，HOL 用 source None 规范化表示这一无结果观察，对应空目标输出，而不是偷偷添加 fallback。只有该特定异常可作此归约；其他错误不得被吞掉。旧验收器把无匹配源判为不完整／对应失败，本轮不修改此验收规则。完整性与功能规格另证，不由部分语义保持推出。

栈机联系仅覆盖良构生成代码；Python 的 AND/OR 对操作数不足使用切片，HOL 明确拒绝下溢，二者在任意手工损坏字节码上不保证一致。HOL 零／一元 AND/OR 属于更广构造器边界，不是当前文本解析器可生成语法。

证明目标：

1. 编译任意表达式在任意原栈上恰好压入其源语义值，原栈不变；包含 NOT 优化。
2. 优先级屏蔽后的每条 guard 恰好对应首个满足分支；任意规则表与布尔环境下 target 输出列表等于 source 的零／一元素列表。
3. 任意输出性质从模型传到 source；模型是否覆盖所有输入、是否满足期望要求仍为独立前提。
4. 固定优先级遗漏、NOT 消去错误及无匹配三类有判别力的小见证；不能用故障证明真实生成错误率。
